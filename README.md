📥 Download Lo Speed
Консольный загрузчик файлов для Windows с поддержкой докачки (resume), автоматического переподключения и прогресс-баром. Идеально подходит для медленного или нестабильного интернета.

✨ Особенности
✅ Докачка (Resume) — продолжает загрузку с того места, где она прервалась

🔄 Автоматическое переподключение — при обрыве связи программа сама переподключается.
 До 10 попыток по умолчанию. Можно настраивать, рекомендую 9999999 

📊 Прогресс-бар — показывает процент, скорость и оставшееся время

📁 Гибкая настройка сохранения — выбор папки и имени файла

🛡️ Обработка ошибок — таймауты, проверка на "зависание", корректное завершение по Ctrl+C

🚀 Простота использования — запустил, ввёл URL и имя файла

🛠️ Технологии
Python 3.8+

Requests — HTTP-клиент

UV — управление зависимостями (быстрее pip)

📦 Установка
1. Установите UV (если ещё не установлен)
Windows (PowerShell):

```powershell
powershell -c "irm https://astral.sh/uv/install.ps1 | iex"
``` 
macOS / Linux:

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```
2. Клонируйте репозиторий
```bash
git clone https://github.com/EvgeniiPetrov/download_lo_speed.git
cd download_lo_speed
```
3. Установите зависимости через UV
```bash
uv sync
```
Это создаст виртуальное окружение и установит все необходимые пакеты.

🚀 Запуск
```bash
uv run main.py
```
Или, если вы активировали виртуальное окружение:

```bash
python main.py
```

Если папка не существует, программа предложит её создать.

Если файл уже существует, выберите действие:

o — перезаписать (overwrite)

r — переименовать (rename), добавит номер к имени

a — отменить (abort)

Наблюдайте за прогрессом:

Для продолжения загрузки просто запустите программу с тем же URL и укажите тот же файл — она продолжит с того места, где остановилась.

⚙️ Как это работает
Механизм докачки
Программа использует HTTP-заголовок Range для запроса определённой части файла:

```http
Range: bytes=1048576-
```
Если сервер поддерживает докачку (ответ с кодом 206 Partial Content), загрузка продолжается с указанной позиции.

Проверка на "зависание"
Если в течение 10 секунд не было получено ни одного байта, программа считает, что соединение "зависло", и автоматически переподключается.

Автоматическое переподключение
При любой ошибке (таймаут, обрыв соединения, отсутствие данных) программа:

Увеличивает счётчик попыток

Ждёт 2-20 секунд (задержка растёт с каждой попыткой)

Продолжает загрузку с того же места

Максимальное количество попыток — 10 (по умолчанию).

📦 Зависимости
Проект использует только один внешний пакет:

requests==2.32.3 — для HTTP-запросов

Все зависимости управляются через UV и описаны в pyproject.toml.

🧪 Тестирование
Для проверки работы программы используйте тестовые URL:

https://speed.hetzner.de/100MB.bin (100 МБ)

https://speed.hetzner.de/1GB.bin (1 ГБ)

http://ipv4.download.thinkbroadband.com/100MB.zip

Проверка докачки
Запустите загрузку большого файла

Подождите 10-20 секунд

Нажмите Ctrl+C — загрузка прервётся

Запустите программу снова с тем же URL и именем файла

Убедитесь, что загрузка продолжилась с прерванного места

🐛 Известные ограничения
Поддержка сервера: Докачка работает только если сервер поддерживает заголовок Range (большинство современных серверов поддерживают)

Изменение файла: Если файл на сервере изменился во время загрузки, докачка может привести к повреждению файла

Только Windows: Тестировалось только на Windows 11, но должен работать и на других ОС
